Student Management System – SAP ABAP

Project Overview

A Student Management System developed using SAP ABAP and the ABAP RESTful Application Programming Model (RAP). This project allows users to manage student records and view student statistics through a Fiori Elements interface.

Technologies Used

- SAP ABAP
- ABAP RESTful Application Programming Model (RAP)
- Core Data Services (CDS Views)
- Behavior Definitions and Implementations
- OData V2
- SAP Fiori Elements
- Eclipse ADT

Features

- Create, read, update, and delete student records
- Validate student information
- Department selection using value help
- Search, filter, and sort student records
- Student dashboard showing total students, highest marks, and average marks
- Department-wise student count

Project Structure

- "CDS-Views/" – CDS view definitions
- "Behavior-Definitions/" – RAP behavior definitions
- "Behavior-Implementation/" – ABAP behavior implementation
- "Service-Definitions/" – Service definition and binding details
- "Screenshots/" – Project screenshots
